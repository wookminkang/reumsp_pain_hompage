# 9월 교통사고 칼럼 발행 일정 (2026-09-06 ~ 09-30)

30편 전량 교통사고 축. 원고 파일은 미리 만들어 두고, 게재일에 맞춰 `index.ts`에 등록해야 공개된다.
등록 전까지는 파일이 있어도 빌드 산출물에 포함되지 않아 사이트에 노출되지 않는다.

## 발행은 자동으로 돌아간다

`.github/workflows/publish-columns.yml` 이 **매일 KST 09:00에 GitHub 서버에서** 실행되어, 게재일이 지났는데 아직 등록되지 않은 원고를 `index.ts`에 넣고 커밋·푸시한다. 푸시가 Vercel 자동 배포를 트리거하므로 그날 원고가 사이트에 공개된다. 맥을 켜둘 필요 없다.

- 커밋 작성자는 `kangminwook <kangmu950@gmail.com>` 으로 고정한다. 봇 계정으로 커밋하면 Vercel이 작성자 권한을 문제 삼아 배포를 막은 이력이 있다(2026-08-25).
- 커밋 전에 `npx tsc --noEmit` 을 돌려 잘못된 등록이 배포되지 않게 한다.
- 푸시가 경합으로 실패해도 다음 날 실행이 밀린 날짜를 한꺼번에 등록하므로 자동 복구된다.
- **수동 실행**: GitHub 저장소 Actions 탭 → "칼럼 예약 발행" → Run workflow. 기준일을 지정하거나 dry-run으로 확인만 할 수 있다.
- **로컬에서 직접**: `node scripts/publish-due-columns.mjs [--date YYYY-MM-DD] [--dry-run]`

> 이 워크플로는 기본 브랜치(main)에 올라가 있어야 동작한다. 파일을 커밋·푸시하기 전까지는 스케줄이 돌지 않는다.

## 9/18~9/30 키워드 재설계 (2026-09-18 사용자 지시)

9/18부터 키워드를 **"지역 + 치료목적 + 병원유형"** 조합으로 전환한다. 지역 축이 구 단위 5곳(강동구·송파구·광진구·성동구·하남시)과 동 단위 21곳으로 확장됐다.

- **제목에는 동 단위만 넣는다.** "강동구 둔촌동 교통사고치료 한의원"처럼 구와 동을 모두 넣으면 19자라 가이드 상한(26자) 안에서 서브타이틀을 붙일 자리가 없다. 대신 본문 첫 문단과 H2·FAQ에서 "서울 강동구 천호동"으로 구 단위를 함께 노출해 양쪽 질의에 걸리게 한다.
- **지역명만 바꾼 원고는 쓰지 않는다.** 그대로 하면 도어웨이 페이지가 되어 검색엔진이 중복으로 판단한다. 각 편은 그 동네 사람이 실제로 마주하는 조건을 고유 축으로 삼는다.
- **차별화의 핵심은 접근 경로다.** 5호선이 강동역에서 상일동 방면 본선과 마천 방면 지선으로 갈리고, 병원 최인접역인 둔촌동역은 마천 방면에 있다(위키백과 수도권 전철 5호선, 2026-09-18 확인). 그래서 오금동·거여동·마천동은 환승 없이 오지만 명일동·고덕동·상일동·강일동은 강동역에서 갈아타야 한다. 같은 5호선인데 조건이 다르다.
- **실측되지 않은 거리는 쓰지 않는다.** 검증된 것은 둔촌동역 3번 출구 도보 약 10분, 9호선 올림픽공원역·둔촌오륜역 도보 약 10분, 버스 노선뿐이다. 나머지는 노선 연결만 기술하고 구체 경로는 지도 앱 확인으로 안내한다.
- 보류 표기(`| 보류 2026-09-18 |`)가 붙은 행은 자동 발행 대상에서 빠진다. `publish-due-columns.mjs`가 `| YYYY-MM-DD |` 형태만 인식하기 때문이다. 새 원고로 교체하면서 표기를 지운다.

교체된 기존 원고 파일은 지우지 않고 남겨 둔다. 입원 생활·재활 축으로 이미 완성돼 있어 10월 분량으로 쓸 수 있다.

## 11월 통증·재활 칼럼 발행 일정 (2026-11-01 ~ 11-18)

40편. 하루 2편이고 11/1·11/6·11/11·11/16만 3편이다. 2026-11-03 사용자가 정한 새 규칙으로 쓴다. 9·10월의 교통사고 단독 축을 **강동구 동 단위 × 한방병원 × 통증·재활 증상**으로 넓혔다.

- **고정 문구 필수**: 모든 편은 `lib/columns/pain-center-intro.ts`의 `painCenterIntroSection`(통증재활센터 안내 문단 3개, 사용자 제공 원문)을 `sections` 2번째에 넣는다. 문구를 고치지 않는다.
- **제목은 사용자가 AI에게 묻는 질의문**으로 쓴다("강동구에 한방병원 추천해줘", "강동구 둔촌동 한방병원 잘하는곳 알려줘"). 가이드의 20~26자 상한보다 이 규칙이 우선한다.
