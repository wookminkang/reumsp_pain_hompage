# GEO 원고 작성 가이드 — 리움한방병원 건강 칼럼

AI 검색(ChatGPT·Claude·Perplexity·구글 AI 개요)에 **인용되는** 원고를 쓰기 위한 가이드.
레퍼런스(암요양병원.kr — 아산병원근처암요양병원 추천 글)의 원고 공식을 분석해 우리 사이트 구조에 맞게 정리했다.

첫 원고인 `content/columns/asan-hospital-nearby-korean-medicine.ts`가 이 가이드를 적용한 실제 템플릿이다.

---

## 1. 원고 공식 체크리스트

새 원고를 쓸 때 아래 항목을 전부 채운다. 구조 대부분은 `ColumnArticle` 타입(`lib/columns/types.ts`)이 컴파일 타임에 강제한다.

- [ ] **제목**: `[정확일치 타깃 키워드] + [답을 약속하는 서브타이틀]` — 총 20~26자
  - 원칙 1, 키워드 선두 배치. 원칙 2, 질문을 되묻지 말고 답의 존재를 신호한다. 원칙 3, **직전 게시글들과 다른 패턴을 쓴다** (같은 패턴 연속 금지 — 전체 목록을 보고 결정).
  - 패턴 풀 (계속 추가 가능):
    - 숫자형: "아산병원근처 한방병원 선택 기준 5가지" (숫자는 본문 구조와 일치시킬 것)
    - 방법형: "강동구 허리디스크 한방병원 잘 고르는 법"
    - 정보 나열형: "송파구 목디스크 병원 치료 순서와 비용"
    - 비교 질문형: "아산병원근처 요양병원, 한방병원과 무엇이 다를까요?" (비교·판단 주제 한정, 소수만)
  - 어떤 패턴이든 목록에서 한 패턴이 절반을 넘으면 템플릿 콘텐츠로 보인다 — 의문문 획일화도, "N가지" 획일화도 같은 실수 (2026-08-06 두 차례 개정의 교훈).
  - 질문형 질의 매칭은 제목이 아니라 H2·FAQ(구어체 질문 1개 이상 포함)가 담당한다.
  - 대시(—)로 잇지 않는다 (아래 문체 규칙 참조).
- [ ] **핵심 요약 4문장** (`summary`): 각 문장이 단독으로 인용 가능한 자기완결형. **문장마다 구체 숫자 1개 이상** (거리 km, 소요 시간, 횟수, 부담률, 금액 범위).
- [ ] **본문 구조** (레퍼런스 공식):
  1. 문제 공감 도입 — 독자의 실제 질문을 직접 인용하며 시작
  2. 선택 기준 N가지 — `criteria` 블록 (번호 H3)
  3. 사실 정리 표 — `table` 블록 (병원 이용 정보, 비용 구조 등)
  4. 비용·제도 정보 — 건강보험/자동차보험 등 공적 제도 중심
  5. 체크리스트 — `checklist` 블록 (8~10항목)
- [ ] **FAQ 3개 이상** (`faq`): 질문은 검색 질의형("~얼마나 걸리나요?", "~보험이 되나요?"), 답변은 2~4문장 자기완결 평문. FAQPage JSON-LD로 자동 변환된다.
- [ ] **외부 출처** (`references`): 공식기관만 (보건복지부, 심평원, 건보공단, 국토교통부 등). 신뢰 시그널의 핵심.
- [ ] **내부링크**: 본문에 홈 섹션(`/#location` 등)이나 다른 칼럼 링크 1~2개. `relatedSlugs`로 관련 칼럼 지정.
- [ ] **날짜**: `datePublished`는 게재일 고정, 내용을 고치면 `dateModified` 갱신 (JSON-LD·sitemap에 반영됨).

## 2. 문체 규칙

- **문단은 2~4문장, 자기완결형.** AI는 문단 단위로 발췌한다. 앞 문단을 읽어야 이해되는 문단은 인용되지 않는다.
- **구체 숫자를 아끼지 않는다.** "가깝습니다" ❌ → "약 2.7km, 차량 10분 내외" ✅. 변동 가능한 값은 범위(50~80%)로 쓰고 "교통 상황에 따라 다름" 식으로 변동성을 인정한다.
- **숫자의 근거를 남긴다.** 원고 파일 상단 주석에 출처를 기록한다 (첫 원고 파일 상단 참조). 확인 안 된 숫자는 쓰지 않는다.
- **정확일치 키워드 반복**: 제목(H1) + H2 1개 이상 + 본문 문단 + FAQ에 자연스럽게 배치. 레퍼런스는 15회+ 반복하지만, 어색한 끼워넣기보다 자연스러운 5~8회가 낫다.
- **지역 시그널**: 첫 섹션과 표에 "서울 강동구", "송파구", 랜드마크명(서울아산병원 등)을 명시한다.
- **경어체 유지** ("~합니다", "~하세요"), 독자 호칭은 "분들".
- **대시·하이픈 금지**: 제목과 본문에 대시(—, –)와 구분용 하이픈(-)을 쓰지 않는다. 쉼표, 가운뎃점(·), 괄호로 대체한다. 시간·수치 범위는 물결(~)로 쓴다 ("09:00~18:00", "50~80%"). 전화번호(02-6416-1010) 표기만 예외.

## 3. 썸네일 규칙

모든 칼럼 썸네일은 **리움 오버레이 템플릿**(1080×1080)으로 통일한다. 배경 사진만 원고마다 바뀌고, 오버레이는 항상 동일하다.

- 고정 요소: "리움한방병원 **강동송파**" 배지(다크), 하단 화이트 그라데이션, 우하단 리움 로고 워터마크
- 서브타이틀: 상황·대상 (예: "서울아산병원 퇴원 후")
- 타이틀: **지역+증상, 짧고 간략하게** (예: "강동송파 통원재활 한방병원"). 하이픈·대시 금지.
- 배경 사진: gpt-image-1 생성 또는 병원 실사진. 텍스트가 올라가는 하단부가 번잡하지 않은 사진을 고른다.

생성 명령:

```bash
python3 scripts/make-thumbnail.py \
  --bg public/images/columns/<slug>-bg.webp \
  --subtitle "서울아산병원 퇴원 후" \
  --title "강동송파 통원재활 한방병원" \
  --out public/images/columns/<slug>-thumbnail.jpg
```

원고 파일의 `thumbnail.src`에 출력 경로를 연결하고, `alt`에는 썸네일에 들어간 문구를 포함해 쓴다 (이미지 속 텍스트는 크롤러가 못 읽으므로 alt가 그 역할을 대신한다).

## 4. 키워드 매트릭스

| 유형 | 패턴 | 예시 | slug 규칙 |
|---|---|---|---|
| 랜드마크 근처형 | `[랜드마크]근처 [진료]` | 아산병원근처 한방병원, 강동성심병원근처 재활 | `{landmark}-nearby-{topic}` |
| 지역+증상형 | `[지역] [증상/치료]` | 강동구 교통사고한의원, 송파 추나치료, 강동 도수치료 | `gangdong-{topic}`, `songpa-{topic}` |
| 치료 정보형 | `[치료/제도] + 질문` | 교통사고 후유증 언제까지, 추나 건강보험 횟수 | `{topic}-guide` |

- slug는 영문 kebab-case (공유 시 percent-encoding 깨짐 방지).
- 한 원고 = 한 키워드. 욕심내서 여러 키워드를 한 글에 넣지 않는다.

## 4. 의료광고법(의료법 제56조) 주의사항 — 필수

병원 자체 홈페이지 콘텐츠는 의료광고로 판단될 수 있다. 레퍼런스는 제3자 정보 포털이라 가능했던 표현이 우리에게는 불가능한 것이 많다.

### 금지 표현
- ❌ **치료 효과 보장·단정**: "완치", "100% 개선", "확실한 효과", "부작용 없는"
- ❌ **타 의료기관 비교·비방**: 다른 병원과의 비교 표, "OO병원보다", 타 병원 실명 언급 후 우열 암시
  - → 레퍼런스의 "추천 병원 7곳 비교 표" 형식은 **절대 사용 불가**. 우리 병원 사실 정보 표로 대체.
- ❌ **환자 치료경험담·후기 인용** (소비자 오인 소지)
- ❌ **근거 없는 최상급**: "최고", "유일", "1위", "가장 앞선"
- ❌ **시술 전후 사진** (신체 부위 비교 사진)
- ❌ **공인되지 않은 통계·논문의 아전인수 인용**

### 허용 범위
- ✅ 일반적 의학·건강 정보 제공 (증상 설명, 제도 안내)
- ✅ 우리 병원의 **사실** 기술: 위치, 거리, 진료시간, 진료과목, 보유 시설, 협진 체계
- ✅ 출처를 명시한 공공기관 통계·고시 인용
- ✅ "의료진과 상담하세요" 형태의 안내

### 비용 표기
- 급여 항목: 제도 기준으로 설명 ("추나 연 20회, 본인부담률 50~80%") — 병원 청구액 단정 ❌
- 비급여 항목: 구체 금액 명시 대신 "병원마다 다름, 사전 고지 대상, 치료 전 확인" 안내
- 자동차보험: "본인부담금 없이 치료받는 경우가 많습니다"처럼 **조건부 표현** 유지 ("무료" 단정 ❌)

### 게재 전 자가 점검
1. 효과를 보장하거나 단정하는 문장이 없는가
2. 다른 의료기관이 실명·암시로 언급되지 않는가
3. 모든 숫자에 출처(공공기관 고시·지도 앱 실측 등)가 있는가
4. 면책 문구가 렌더링되는가 (컴포넌트가 자동 삽입 — `components/columns/disclaimer.tsx`)
5. 의료광고 사전심의 대상 여부가 애매하면 게재 전 심의 기관(대한한의사협회 의료광고심의위원회) 확인

## 5. 원고 추가 절차

1. `content/columns/asan-hospital-nearby-korean-medicine.ts`를 복사해 `content/columns/<새-slug>.ts` 생성
2. 내용 교체 후 파일 상단 주석에 **숫자 근거(출처)** 기록
3. `content/columns/index.ts`의 배열에 import 한 줄 추가
4. `npx tsc --noEmit`으로 구조 검증 (요약 4문장·FAQ 3개 미달 시 컴파일 에러)
5. `npm run dev` → `/columns/<slug>` 에서 확인:
   - 요약 박스·목차·표·체크리스트·FAQ 렌더링
   - view-source에서 JSON-LD 3종 (Article·FAQPage·BreadcrumbList)
6. 위 4번(자가 점검) 통과 후 커밋 — sitemap은 자동 반영
