# 병원 담당자 확인 필요 질문 리스트

홈페이지·칼럼에 정확히 표기하기 위해 담당자 확인이 필요한 사항입니다.
답변을 받으면 이 문서에 기록하고, 해당 표기(오시는길·JSON-LD 스키마·칼럼)를 일괄 통일합니다.

## 1. 진료 시간 (최우선 — 현재 사이트 내 표기가 서로 다름)

현재 히어로에는 "365일, 야간·공휴일 진료/입원 가능", 오시는길·스키마에는 "평일 09~18시 / 토 09~13시 / 일·공휴일 휴진"으로 되어 있습니다.

- [ ] 일요일·공휴일에도 **외래 접수**가 가능한가요? 가능하다면 접수 시간은? (예: 일·공휴일 09~13시)
- [ ] **야간 진료**는 몇 시까지인가요? 매일인가요, 특정 요일인가요?
- [ ] "365일 진료"의 정확한 의미는? (a) 외래도 365일 (b) 외래는 월~토, 입원 병동·응급 대응만 365일
- [ ] 점심시간(진료 휴게)이 있나요? 있다면 몇 시부터 몇 시?

→ 답변에 따라 수정할 곳: `lib/clinic.ts` hours, JSON-LD openingHoursSpecification, 오시는길 섹션, 칼럼 진료시간 표기

## 2. 의료진 (⚠️ 현재 칼럼에 게재 중 — 틀리면 즉시 수정 필요)

현재 홈페이지·칼럼에 "진료원장 6인: 도성국 대표원장, 한아람·최대홍·강소현·김수정·이성덕 원장"으로 게재되어 있습니다.

- [ ] 진료원장 **인원수와 성함·직함이 정확한가요?** (추가·퇴사·표기 오류 확인)
- [ ] 각 원장님의 **전문의 자격**(한방재활의학과 등)과 전문 진료 분야는?
- [ ] 칼럼에 "감수: OOO 원장" 표기를 넣으려면 실제 감수 프로세스가 필요합니다. 감수 담당 원장님을 지정할 수 있나요?
- [ ] 의료진 프로필(약력·학회 활동)을 홈페이지에 게재할 수 있나요? (AI 인용 신뢰도에 직결)

## 3. 병상·병실 (⚠️ 현재 칼럼에 게재 중 — 틀리면 즉시 수정 필요)

현재 "입원 병동 65개 병상, 1인실·2인실·3인실·4인실 구비 (2층~6층)"로 게재되어 있습니다.

- [ ] **총 병상 수 65개가 정확한가요?** (허가 병상 기준)
- [ ] **입원실(병실) 개수**는 총 몇 개인가요? 층별 안내 기준으로는 25실(6층 3실 + 5층 6실 + 4층 6실 + 3층 6실 + 2층 4실)로 계산되는데 맞나요?
- [ ] 병실 타입별 개수는? (1인실 O개, 2인실 O개, 3인실 O개, 4인실 O개)
- [ ] 층별 호실 범위가 정확한가요? (6층 601~603호 / 5층 501~506호 / 4층 401~406호 / 3층 301~306호 / 2층 201~204호)

## 4. 진료·서비스 관련

- [ ] **첩약 건강보험 시범사업** 참여 기관인가요? (참여 시 칼럼에 표기 가능)
- [ ] **셔틀 운행 또는 보호자 동행 서비스**가 있나요? (아산병원 통원 환자 대상 — 있으면 강력한 콘텐츠 소재)
- [ ] 서울아산병원 등과 **공식 진료협력(협력의료기관) 관계**가 있나요? (공식 협약이 있으면 표기 가능, 없으면 현행대로 언급 금지 유지)
- [ ] 고압산소치료·고주파온열치료(BSD-2000)의 건강보험 적용 여부는? (비급여라면 칼럼에서 비용 표현 주의 필요)

## 5. 비급여 고지 (의료법 의무)

- [ ] 비급여 진료비용 고지 페이지(가격표)가 준비되어 있나요? 병원급은 홈페이지 게재 의무가 있습니다. 항목·금액 리스트를 받으면 페이지로 만들 수 있습니다.
